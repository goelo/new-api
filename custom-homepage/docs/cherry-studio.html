Cherry Studio 配置教程

在 Cherry Studio 中通过自定义服务商接入 Forest API 平台，快速使用 Claude、GPT 和 Gemini 模型。

Cherry Studio 是一款支持多模型的桌面 AI 客户端，界面友好，适合日常对话和创作场景。通过自定义服务商功能，可以轻松接入 Forest API。

第一步：下载安装 Cherry Studio

前往 Cherry Studio 官网 下载对应系统的安装包，按提示完成安装。

支持 Windows、macOS、Linux 三个平台。

第二步：添加自定义服务商

打开 Cherry Studio，进入 设置 → 模型服务，点击左下角 添加服务商。

填写以下信息：

服务商名称：Forest API API 地址：https://forestapi.com/v1 API Key：YOUR_API_KEY

请将 YOUR_API_KEY 替换为在 控制台 页面中复制的 API Key。

第三步：添加模型

在刚创建的 Forest API 服务商下，点击 添加模型，输入模型名称。常用模型：

claude-opus-4-5 claude-sonnet-4-5 claude-haiku-4-5 gpt-4o gpt-4o-mini gemini-2.0-flash

添加完成后，点击 检测 按钮验证连接是否正常。

第四步：开始对话

回到主界面，点击 新建对话，在右上角模型选择器中切换到 Forest API 下的模型，即可开始使用。
