Codex (OpenAI) 配置教程

安装并配置 Codex CLI 工具，通过配置文件连接 Forest API 平台。

Codex CLI 是 OpenAI 官方命令行工具，支持在终端中使用 GPT 系列模型进行 AI 编程辅助。
开始前请先完成 Node.js 环境安装教程。

第一步：安装 Codex CLI

打开终端，运行以下命令全局安装：

npm install -g @openai/codex

macOS / Linux 遇到权限问题时：

sudo npm install -g @openai/codex

验证安装

codex --version

显示版本号即安装成功。

第二步：设置环境变量

OPENAI_API_KEY — 你的 API Key
OPENAI_BASE_URL — 自定义服务地址

临时设置（当前会话）

Windows (PowerShell)：

$env:OPENAI_API_KEY = "YOUR_API_KEY" $env:OPENAI_BASE_URL = "https://forestapi.com/v1"

macOS / Linux：

export OPENAI_API_KEY="YOUR_API_KEY" export OPENAI_BASE_URL="https://forestapi.com/v1"

永久设置

macOS (zsh)：

echo 'export OPENAI_API_KEY="YOUR_API_KEY"' >> ~/.zshrc echo 'export OPENAI_BASE_URL="https://forestapi.com/v1"' >> ~/.zshrc source ~/.zshrc

Linux (bash)：

echo 'export OPENAI_API_KEY="YOUR_API_KEY"' >> ~/.bashrc echo 'export OPENAI_BASE_URL="https://forestapi.com/v1"' >> ~/.bashrc source ~/.bashrc

请将 YOUR_API_KEY 替换为在 控制台 页面中复制的 API Key。

第三步：开始使用

在项目目录中运行：

codex

也可以直接传入任务描述：

codex "帮我写一个读取 CSV 文件的 Python 脚本"
