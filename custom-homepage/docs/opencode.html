OpenCode 配置教程

通过配置文件将 OpenCode 接入 Forest API 平台，快速完成 Claude、GPT 和 Gemini 模型配置。

OpenCode 是一个开源的终端 AI 编程助手，支持多种模型提供商。本教程将引导你配置 Forest API 作为后端服务。

第一步：安装 OpenCode

npm install -g opencode-ai

验证安装

opencode --version

第二步：创建配置文件

在 home 目录创建配置文件 ~/.opencode/config.json：

{ "providers": { "anthropic": { "apiKey": "YOUR_API_KEY", "baseURL": "https://forestapi.com" }, "openai": { "apiKey": "YOUR_API_KEY", "baseURL": "https://forestapi.com/v1" } }, "defaultModel": "claude-sonnet-4-5" }

请将 YOUR_API_KEY 替换为在 控制台 页面中复制的 API Key。

支持的模型

通过 Forest API，OpenCode 可以使用以下模型：

claude-opus-4-5 claude-sonnet-4-5 claude-haiku-4-5 gpt-4o gpt-4o-mini gemini-2.0-flash

第三步：开始使用

在项目目录中运行：

opencode
