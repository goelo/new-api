Claude Code 配置教程

安装并配置 Claude Code CLI 工具，连接 Forest API 平台。

Claude Code 是 Anthropic 官方 CLI 工具，强大的 AI 编程助手。本教程将引导你完成安装和配置。
开始前请先完成 Node.js 环境安装教程。

第一步：安装 Claude Code

打开终端（Windows 使用 PowerShell 或 CMD），运行以下命令：

npm install -g @anthropic-ai/claude-code

这个命令会从 npm 官方仓库下载并安装最新版本的 Claude Code。

如果在 macOS / Linux 上遇到权限问题，可以使用 sudo：

sudo npm install -g @anthropic-ai/claude-code

验证安装

安装完成后，输入以下命令检查是否安装成功：

claude --version

如果显示版本号，恭喜你！Claude Code 已经成功安装了。

第二步：设置环境变量

为了让 Claude Code 连接到 Forest API 平台，需要设置两个环境变量：

ANTHROPIC_BASE_URL — 服务地址
ANTHROPIC_AUTH_TOKEN — 你的 API Key

临时设置（当前会话）

Windows (PowerShell)：

$env:ANTHROPIC_BASE_URL = "https://forestapi.com" $env:ANTHROPIC_AUTH_TOKEN = "YOUR_API_KEY"

macOS / Linux：

export ANTHROPIC_BASE_URL="https://forestapi.com" export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"

永久设置

Windows (PowerShell)：

[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://forestapi.com", [System.EnvironmentVariableTarget]::User) [System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "YOUR_API_KEY", [System.EnvironmentVariableTarget]::User)

macOS (zsh)：

echo 'export ANTHROPIC_BASE_URL="https://forestapi.com"' >> ~/.zshrc echo 'export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"' >> ~/.zshrc source ~/.zshrc

Linux (bash)：

echo 'export ANTHROPIC_BASE_URL="https://forestapi.com"' >> ~/.bashrc echo 'export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"' >> ~/.bashrc source ~/.bashrc

请将 YOUR_API_KEY 替换为在 控制台 页面中复制的 API Key。

第三步：开始使用

现在你可以开始使用 Claude Code 了！

claude

启动后，Claude Code 会分析当前目录的代码，并提供智能编程辅助。更多使用说明请参考 Anthropic 官方文档。
